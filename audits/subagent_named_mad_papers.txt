# Literature audit for scd-mas (SCD) — verified against primary sources, 2026-09-30

Mechanism keys: (a) immutable private/incumbent state preserved during peer exposure; (b) peer info in a separate speculative/shadow branch; (c) transition/delta represented separately; (d) explicit COMMIT/ROLLBACK validator; (e) core method for multi-agent reasoning (not tool exec / self-correction / trajectory rollback).

**Bottom line: no audited paper implements the SCD chain. Zero hits on (a)+(b)+(c)+(d) jointly; nobody processes peer info in a per-agent speculative branch with a commit/rollback gate.** Two near-misses are flagged below as phantom/wrong-ID — do not cite them as named.

**1. AgentAuditor** — "Auditing Multi-Agent LLM Reasoning Trees Outperforms Majority Vote and LLM-as-Judge." Wei Yang (first author), et al. (USC). 2026. arXiv:2602.09341 (v1 2026-02-10, v2 2026-09-03), no venue listed — preprint. https://arxiv.org/abs/2602.09341
(a) No. (b) No — Reasoning Tree is built post-hoc over already-generated traces; "drop-in adjudication module that replaces only the final aggregation stage," no agent state touched during generation. (c) No per-agent delta; divergence between agents is explicitly represented as Critical Divergence Points in the tree. (d) Partial at best — an external Auditor adjudicates among existing branches at divergence points; it selects, never commits/rolls back a per-agent transition. (e) Yes — core aggregation method replacing majority vote / LLM-as-judge.
Setting: MAD reasoning aggregation. Benchmarks: GSM8K, MATH, AMC, MMLU (+ MuSiQue, TriviaQA in appendix). Frameworks: LLM-Debate, DyLan, GPTSwarm, AgentPrune. Models: Llama-3.1-8B-Instruct, Llama-3.2-3B-Instruct, Qwen2.5-7B/3B-Instruct. Code: https://github.com/weiyang930/AgentAuditor.git
Name collision warning: "AgentAuditor: Human-Level Safety and Security Evaluation for LLM Agents," Hanjun Luo, arXiv:2506.00641, NeurIPS 2025 (https://arxiv.org/abs/2506.00641) is a different paper (agent safety evaluation). Cite the 2602.09341 one for multi-agent reasoning.

**2. Free-MAD** — "Free-MAD: Consensus-Free Multi-Agent Debate." Yu Cui (first author), Hang Fu, Haibin Zhang, Licheng Wang, Cong Zuo. 2025. arXiv:2509.11035 (v1 2025-09-14), cs.AI/cs.CR, no venue — preprint. https://arxiv.org/abs/2509.11035
(a) Partial — prompt-level only: agents are told "If you cannot definitively determine whether others are correct, you should retain your own conclusion"; nothing programmatic preserves state. (b) No. (c) No — a score dictionary tracks answer evolution across the whole trajectory as a scoring signal, not a delta structure. (d) No gate on revision (answers the caller's question: revisions are NOT gated — updating is entirely prompt-driven); the deterministic score mechanism {w1..w4}={20,25,30,20}, abandoned-answer penalty, retention reward, correction factor f=(k+1)^-1) is a final-selection rule, not a per-transition commit/rollback validator. (e) Yes — core MAD method, single-round debate.
Benchmarks (8): GSM-Ranges (L4, L6), AIME2024, AIME2025, MATH500, StrategyQA, Logical Fallacies (MMLU), AICrypto. Models: Qwen1.5-7B-Chat, Qwen2.5-72B-Instruct, DeepSeek-V3 (N=3-4 agents). No official code URL found on arXiv page.

## The 3 works closest to SCD's five-factor chain

1. **Debate or Vote** (arXiv:2508.17536, NeurIPS 2025 Spotlight) — the only audited work with an explicit immutable-incumbent construct: MAD-oracle "locks" correct answers across rounds (factor a, as an oracle upper bound), and its interventions are explicit gates on belief updates (factor d, heuristic). Core MAD analysis (factor e). Covers {a, d, e}; has nothing like a speculative branch or delta.
2. **Free-MAD** (arXiv:2509.11035) — incumbent retention pressure at the prompt level ("retain your own conclusion unless definitive evidence") plus a deterministic aggregation score that rewards answer persistence and penalizes abandonment — incumbent-weighted aggregation (soft a; no per-transition gate). Core MAD method (e). Covers {a(partial), e}; revisions are explicitly NOT gated.
3. **AgentAuditor** (arXiv:2602.09341) — separately represented reasoning branches with an external validator adjudicating at divergence points (factors b/c/d in post-hoc, aggregation-time form) and a core multi-agent reasoning method (e). Covers {b-adjacent, c-adjacent, d-adjacent, e}; nothing is preserved per-agent, and adjudication happens only at the end.

Runner-up: Mem++ (arXiv:2610.02002) — the only paper with a hard never-overwrite (immutable incumbent) principle, but single-agent memory management; and Learning What to Remember (arXiv:2609.37930) — the cleanest explicit commit gate (MGPO), but single-agent.

**Novelty verdict:** each individual factor exists somewhere in weak form (oracle-locked answers, prompt-level retention, post-hoc branch adjudication, memory-commit gating), but no audited paper combines immutable committed state + speculative processing of peer info + separate delta + explicit commit/rollback validator inside the multi-agent reasoning loop. All URLs above were fetched directly (arXiv abs/html pages or the arXiv API); the only UNVERIFIED items are the Cost of Consensus's archival status, the phantom E2-Explainer/E2LLM entry, and benchmark/model names for Not All Flips and Minority Sentinel (abstract pages do not list them).
